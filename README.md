# Como rodar o projeto Expo

Este é um projeto desenvolvido com **Expo**.  
Siga os passos abaixo para rodar a versão web da aplicação.

## 📦 Instalação
Primeiro, instale as dependências do projeto:

```bash
npm install
````
🚀 Executar no navegador (Web)

Para iniciar o projeto na versão Web, rode o comando:
```bash
npm run web
